# پلنر من — راهنمای انتشار روی وب (Vercel)

این پوشه یه پروژه‌ی کامل و آماده‌ست. با دنبال‌کردن مراحل زیر (بدون نیاز به دانش برنامه‌نویسی و بدون نیاز به ترمینال) می‌تونی این اپ رو روی یه آدرس اینترنتی واقعی منتشر کنی و به هوم‌اسکرین گوشیت اضافه کنی. بعد از انتشار، جست‌وجوی خودکار فیلم (OMDb) هم بدون هیچ محدودیتی کار می‌کنه.

## مرحله ۱ — ساخت اکانت گیت‌هاب (GitHub)
1. برو به [github.com](https://github.com/signup) و یه اکانت رایگان بساز (فقط ایمیل لازمه).

## مرحله ۲ — ساخت یه مخزن (Repository) جدید
1. بعد از ورود، روی دکمه‌ی سبز **New** (یا **+** بالای صفحه) بزن.
2. یه اسم بده، مثلاً `persian-planner`.
3. گزینه‌ی **Public** رو انتخاب کن.
4. روی **Create repository** بزن.

## مرحله ۳ — آپلود فایل‌ها
1. توی صفحه‌ی مخزنی که تازه ساختی، روی لینک **uploading an existing file** بزن (یا از منوی Add file گزینه‌ی Upload files رو بزن).
2. تمام فایل‌ها و پوشه‌های داخل این پکیج (package.json، vite.config.js، index.html، پوشه‌ی src و بقیه) رو بکش و همونجا رها کن.
3. پایین صفحه روی **Commit changes** بزن.

## مرحله ۴ — اتصال به Vercel
1. برو به [vercel.com](https://vercel.com) و با همون اکانت گیت‌هاب وارد شو (دکمه‌ی Continue with GitHub).
2. روی **Add New... → Project** بزن.
3. مخزن `persian-planner` رو از لیست پیدا کن و **Import** بزن.
4. تنظیمات پیش‌فرض (Framework: Vite) رو دست نزن و روی **Deploy** بزن.
5. بعد از چند ثانیه یه لینک اینترنتی بهت می‌ده (مثلاً `persian-planner.vercel.app`) — همینه، اپت آماده‌ست!

## مرحله ۵ — افزودن به هوم‌اسکرین
1. لینکی که Vercel داد رو توی **سافاری** باز کن.
2. دکمه‌ی Share (مربع با فلش رو به بالا) رو بزن.
3. گزینه‌ی **Add to Home Screen** رو انتخاب کن.

## نکته‌ی مهم درباره‌ی واچ‌لیست
همون کلید رایگان OMDb که قبلاً گرفتی رو دفعه‌ی اول که وارد تب واچ‌لیست میشی وارد کن. چون این نسخه دیگه توی محیط کلود اجرا نمی‌شه، محدودیت شبکه‌ای که قبلاً باهاش مواجه بودی اینجا وجود نداره و جست‌وجو باید بدون مشکل کار کنه.

## اگه بعداً خواستی چیزی رو تغییر بدی
هر وقت فایل `src/App.jsx` رو توی گیت‌هاب ویرایش و ذخیره کنی، Vercel به‌صورت خودکار نسخه‌ی جدید رو منتشر می‌کنه — نیازی به هیچ کار اضافه‌ای نیست.
